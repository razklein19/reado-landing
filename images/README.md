## Book Cover Images

Not stored here. The book carousel reads published books straight from Supabase
(`src/lib/books.js`), so covers and audio come from the `book-covers` and
`section-audio` storage buckets and update themselves when a book is published
in the admin dashboard. Nothing to copy.
